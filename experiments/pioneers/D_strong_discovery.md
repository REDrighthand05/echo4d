# Pioneer D — 强发现式参照物扫描（泛化试验）

**问题**：不预设锚点，把片子翻个底朝天——凡是"真实尺寸可知"的物体全部发现、
全部分类、能量的都量，再看多个独立锚点能不能互相咬合、收紧误差。这条路能走多远？
**结论：走得通，但有明确的边界。** 这间房里盘出 **20 类候选**，真正能当锚的只有
**3 个家族**（86 面板、门扇、笔记本屏幕）；三者独立给出 **0.248–0.253 米/单位**，
两两相差 ≤2.1%，共识中心 **≈0.249 米/单位**，可信误差由单锚的 ±10% 收紧到
**约 ±5%**。共识还当场否决了两个错误尺寸假设（门=800mm、笔记本=15.6"），
并标出面板家族里一条 +24% 的离群读数。**失败的主因不是"认不出"，而是"量不准"：
遮挡、太薄、太小、尺寸离散不可辨——发现得到 ≠ 量得到。**

方法与 A 完全同源（逐帧深度 + 该帧锚点拟合反投影，确定性、无投票）；
新增两件：①同一点跨帧投影复测（把一帧里定位的端点投影到其他帧、用那帧自己的
深度再量一遍，测重复性）；②离散尺寸假设（门宽、屏幕尺寸这类只有几个标准值的）
全部带入共识裁决，不许单锚独断。判定规则先行：**可靠** = ≥3 视角可测且与面板
尺度在联合误差内一致；**可用但弱** = 可测、一致性边际或需共识帮选尺寸；
**不可用** = 说明原因。

## 2. 三个可用锚的测量明细

### 2.1 86 面板（沿用 A，本轮复验）
A 的 7 次测量：0.237 / 0.242 / 0.249 / 0.253 / 0.264 / 0.275 / 0.309，
中位数 **0.253**，MAD-σ ≈ 0.016；内核交叉验证 0.261 / 0.302。
本轮用独立的视觉定位端点在 frame_00310 复测三联排：宽 0.970 单位 → 0.266，
高 0.305 单位 → 0.282——比 A 的端点系统性内缩约 6%（端点定位口径差，
不是深度差），仍落在家族区间内。**形状判别**：单块面板在图像中近正方形，
排除同为国标的 120 型（120×74mm，长宽比 0.62）——目录必须带这条判别。

### 2.2 门扇（新发现）
顶边在所有视角都被画幅切掉，**门高不可测；门宽可测**（中段两竖边无遮挡；
底部两角被床挡，已弃）。同一宽度线段在 4 帧复测：
frame_00180 三个高度 2.698 / 2.749 / 2.800，跨帧投影复测
00179 / 00181 / 00182 = 2.810 / 2.857 / 2.859——**中位 2.805 单位，散布 ±2%**，
是本轮重复性最好的大尺寸量测。离散假设裁决：
- 700mm（小户型/次门标准）→ 尺度 **0.2496**
- 800mm（最常见卧室门）→ 尺度 0.2852（被共识否决，见 §3）
把手高度校验尝试失败（把手小而凸出，单点深度被污染，读数 2.83 单位 ≈ 0.71m
不可信）——小而凸的部件不进锚点量法，记入教训。

### 2.3 笔记本屏幕（新发现）
frame_00194 全屏可测：宽 1.254 / 1.222，高 0.743 / 0.708，
均值 W 1.238、H 0.726，**对角线 1.435 单位**；W/H = 1.706
（16:9 = 1.778，16:10 = 1.600——偏向 16:9 但分不干净，H 边噪声 ±5%）。
以对角线定尺寸等级（与长宽比无关）：共识尺度下对角线 = 363mm，
距 14"（355.6mm）+2%，距 15.6"（396.2mm）−8% → **14" 级**。
尺度（14" 对角线）= **0.2478**；按 16:9 的宽/高分别算 0.2503 / 0.2401，
内部散布 ±2%。型号本身不可辨（通用蓝灰本、Intel 贴纸），
只能定到"尺寸等级"——这正是类别 ② 的常态：**认得出"类"，认不出"型"，
靠离散等级 + 共识裁决补上最后一环。**

## 3. 多锚共识

| 锚家族 | 尺度（米/单位） | 家族内散布 | 备注 |
|---|---|---|---|
| 86 面板 | 0.253 | σ≈0.016（7 读数） | 含 1 条离群 0.309 |
| 门扇（700mm 假设） | 0.2496 | 复测 ±2% | 尺寸离散，需共识选型 |
| 笔记本（14" 对角线） | 0.2478 | 内部 ±2% | 尺寸等级，需共识选型 |

- **一致性**：三家中心两两最大差 0.0052 = **2.1%**——三个互不相关的物体
  家族（墙面五金 / 建筑构件 / 电子产品）落进同一条窄带。
- **共识中心**：逆方差加权 **0.249 米/单位**，纯统计 σ ≈ 0.005（±2.1%）。
- **诚实折扣**：三家共用同一条深度管线，共模偏差（深度模型在某些距离上的
  系统性偏）不会被共识抵消——故对外口径只收到 **±5%**（单锚 ±10% 的一半），
  不冒用 ±2%。
- **否决错误假设（共识的排雷功能，已实证）**：门=800mm 要求尺度 0.2852，
  距共识 4.5 个门家族 σ；笔记本=15.6" 要求 0.2761，距共识 3.4σ——两个
  "看起来更常见"的尺寸都被另外两家联手否决。**若只拿门当锚并默认 800mm，
  尺度会错 +14%。** 结论：离散尺寸物永远不许单锚独断，必须过共识；
  锚的排序按"尺寸确定性"而非"个头/显眼程度"。
- **标出离群读数**：面板家族的 0.309（frame_00016 左面板高）距共识 +24%，
  共识口径下它会被自动标红——单锚时代它只能靠人工剔除。
- 共识尺度下复核全屋：房间 2.61×2.94m、路线 18.0m、层高下限口径 2.49m，
  全部合理，无一项需要特殊假设。

**总判定（多锚共识）**：能收紧（±10% → ±5%），且能排雷（否决错尺寸、
标出离群读数）——两个作用都实证了。收紧的上限被共模偏差封顶，
要再往下压，只能引入与深度管线无关的第二量法（如稀疏三角化几何），
那是下一轮的事。

## 4. 失败模式归纳（给产品化发现阶段的硬约束）

1. **遮挡/切边**（硬盘、门的底角）：物体在场、尺寸完美，量不到。约束：
   目录条目要写"最小可见比例"，且发现阶段应跨帧累计可见性，
   单帧缺角不算发现失败、多帧都缺才算。
2. **太薄**（词典书脊、纸）：逐帧深度在薄物边缘双向渗色，两视角能差出
   一倍。约束：可测维度应避开薄边；书脊高这类"薄物长边"量法先天不稳，
   除非换稀疏点量法。
3. **太小**（硬盘在融合云里、易拉罐）：经验门槛——可测边长最好 ≥0.8 场景
   单位（≈20cm）；0.35 单位级（A 的硬盘口径）深度噪声占比 ≥±30%。
4. **尺寸离散不可辨**（门、笔记本）：真实尺寸是一组候选值而非一个值。
   约束：目录必须以"候选集"登记，发现阶段输出全部候选的尺度，
   由共识裁决；裁决不出时降级为校验量，不许硬锚。
5. **认得出类、认不出型**（笔记本、手机、充电头）：类别 ② 的常态。
   能定到尺寸等级的（屏幕对角线）可用；定不到的（手机）直接淘汰。
6. **软/可变形**（纸巾包、床品）：尺寸本身不守恒，目录直接拒收。
7. **小而凸的部件**（门把手）：单点深度被污染——量法只许用平面上的
   边/角/面，不许用小凸起。

## 5. 参照物目录格式（产品化发现阶段的输入规格）

一条目录 = 一个"可被发现的参照物家族"。必填字段：

| 字段 | 说明 | 例（86 面板） |
|---|---|---|
| `id` | 稳定键，含地域/标准域前缀 | `cn_std.panel_86` |
| `class` | `standard`（标准定值）/ `discrete`（离散候选集）/ `model`（型号查表）/ `check_only`（仅校验） | `standard` |
| `names` | 中英别名（供识别器匹配） | 86 型面板 / 开关 / 插座 / type-86 wall plate |
| `identifiers` | 识别特征：外观、常见位置、同框伴随物 | 墙面方形面板、单块近正方形、常成组横排、带插孔/开关翘板 |
| `reject_lookalikes` | 易混对象及判别法（必填，防错认） | 120 型面板（120×74mm，长宽比 0.62，明显长方形）→ 以长宽比判别 |
| `dimensions_mm` | 可测维度列表：每条含名称、标称值、公差 | 单块 86±1 × 86±1；连体总宽 = 86×N（N=2:172，3:258，4:344） |
| `alternatives` | `discrete`/`model` 类必填：全部候选尺寸集 | （面板无）门扇例：宽 {700,800,850,900} × 高 {2000,2050,2100} |
| `localisation` | 图像里定位什么：边/角/平面；最小可见比例；最小像素跨度 | 定位外框四边；单边 ≥150px；整块须无遮挡 |
| `measurement` | 量法：用哪些维度、哪种数据（逐帧深度+本帧拟合）、跨视角要求 | 测宽与高（任一即可，两个都测互检）；≥3 视角且来自 ≥2 个机位；复测散布 ≤3% |
| `min_extent_units` | 可测边长的场景单位下限（低于此深度噪声主导） | 0.8（单块面板本身约 0.34——靠多块/连体/多视角攒统计，条目须注明这一例外与攒法） |
| `size_tolerance` | 尺寸本身的不确定（标准公差/离散间隔） | ±1mm（连续）；离散类填候选间隔 |
| `expected_sigma` | 该家族量测的典型相对散布（本轮实测回填） | 面板 ≈6%；门宽 ≈2%；屏幕对角线 ≈2% |
| `consensus_role` | `anchor`（可独立锚）/ `needs_consensus`（离散选型）/ `check`（仅校验） | `anchor` |
| `provenance` | 尺寸出处：标准号/官方规格页/实测回填记录 | GB 86 型通用口径；本轮实测见 A/D 报告 |

第二例（门扇，离散类要点）：`class: discrete`，`alternatives` 如上表，
`consensus_role: needs_consensus`，`localisation` 注明"顶边常被画幅切掉，
优先量宽；底角常被家具遮挡，用中段竖边"，`measurement` 要求同一边跨 ≥3 帧
投影复测。第三例（笔记本屏幕）：`class: discrete`，候选 = 对角线
{13.3, 14, 15.6, 16}" × 长宽比 {16:9, 16:10, 3:2}，量法"先量对角线定级、
再用宽高比在同级内选长宽比"，`consensus_role: needs_consensus`。

## 6. 总判定

- **强发现在这条片子上的射程**：20 类候选 → 3 个可用锚家族（1 可靠 +
  2 可用但弱）+ 1 个观察一致（A4 前边）。命中率不高，但**够用且互备**：
  任何一个家族缺席（没拍到面板、门被切、笔记本合着），另外两家仍能成事
  ——这正是"优质冗余"的实证形态。
- **多锚共识成立**：中心 0.249 米/单位，三家一致性 2.1%，可信误差
  ±10% → ±5%，并实证否决 2 个错误尺寸假设、标出 1 条离群读数。
- **射程的边界不在识别、在量测**：下一轮要扩大战果，优先级是
  ①选帧/拍摄保住大标准物（门只差一个顶边）；②给薄/小物体换量法
  （稀疏三角化几何，而非逐帧深度）；③目录按本格式先行扩充
  （瓷砖 600/800mm、地暖分水器、标准窗扇等本片没有的家族）。
- 本轮全部数字为**估计**：尺度交付口径 = **0.25 米/单位 ±5%（多锚共识，估计）**，
  与 A 的 0.25（±10%）同中心、误差减半。

测量代码与中间产物：`experiments/pioneers/D_work/`（measure_lib.py + 各物体定位裁图）。
