# TUM RGB-D：48 帧融合 / 12 帧留出深度验收（首轮）

**证据类别**：TUM 同一数据集中的真实**未融合**传感器深度帧；并非独立激光扫描的 Mesh 表面真值，也没有自行估计相机轨迹。2026-10-25 实际运行，尚未以新的场景复现。

- 研究决策与预注册：[Issue #3](https://github.com/REDrighthand05/echo4d/issues/3)
- 可复现实验源码：[Draft PR #8](https://github.com/REDrighthand05/echo4d/pull/8)
- 完整 GitHub Actions 运行：[#40190473064](https://github.com/REDrighthand05/echo4d/actions/runs/40190473064)
- 本次代码提交：`13472973e97e3c69fa89d2e4fdb587cfcc0364b8`
- 数据：TUM Freiburg1 XYZ；原始数据下载 **448,204,271 字节**，SHA-256 `'a0236d97b8c30cd93b653656d2b6c293ff7c982a4130ef2a1a8beecdb124ef98'`（此哈希为首次 Actions 官方下载测得并在之后固定）
- 具体 split：训练 48 帧，留出索引 `0,5,...,55` 共 12 帧；这 12 帧没有参与 TSDF 融合。
- 5cm voxel；单帧 RGB-D 已下采样 4 倍；TUM 已知相机位姿，未执行 SfM。
- 48 帧生成 Mesh：5,046 顶点、8,337 三角形、1,703 边界边。

## 预先指定的量化指标（实测）

| 测试量 | 值 | 含义 |
|---|---:|---|
| 有效传感器像素 | 174,284 | 从12张未融合的测深图取得 |
| 同时有 Mesh 预测的像素 | 167,097 | 只在这部分计算深度误差 |
| 有效深度覆盖率 | 95.88% | 缺失预测不默认为正确 |
| 重叠像素 MAE | 3.18 cm | 绝对偏差均值 |
| 重叠像素 RMSE | 11.33 cm | 大偏差受到更强惩罚 |
| 重叠像素绝对偏差中位数 | 1.07 cm | 典型可预测像素 |
| 重叠像素绝对偏差 P95 | 8.11 cm | 95% 的可预测像素误差不超过此值 |
| 3cm 内比例 | 79.25% | 只限有预测的重叠像素 |
| 5cm 内比例 | 89.00% | 同上 |
| 10cm 内比例 | 96.48% | 同上 |

**重要结论**：此数据表明，真实新视角的绝大多数可比像素小误差，但 RMSE 明显大于 MAE / 中位数，提示长尾错误。尚不能把它解释成“真实世界精度 1cm”或“整体重建精度达标”。仍需检查异常区域、相机位姿误差、体素量化、遮挡/动态物体以及 ETH3D 独立激光表面等。

## 证据文件

- `report.json`：机器原始记录，包含官方 URL、SHA、完整分组、12 帧每帧误差和时间、命令、执行状态、局限。
- `train-only-mesh.ply`：从 **48 个训练帧** 生成的真实 Mesh，不是已融合60帧版本。
- `holdout-depth-comparison.png`：误差最高的一个留出帧（帧索引 55）；左为未融合的实测 Z 深度，中为从 Mesh 投影的 Z 深度，右为绝对误差；**蓝色代表有实测但 Mesh 缺失**。

数据原始图像仅由 Actions 下载到短期临时目录，没有提交到 GitHub。自动化测试通过只能证明已声明的算法门禁成立，不等于独立的绝对场景几何精度证明。
