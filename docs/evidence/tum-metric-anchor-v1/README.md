# ECHO4D · 使用实测深度给 RGB 视频相机轨迹定尺寸（首轮实测）

**证据等级：实拍 TUM RGB 视频 → 真正的 COLMAP 自动定位 → 三张深度传感器测量标定比例 → 七张未参与标定的深度验证。** 这不是“纯彩色视频自动推得房间大小”，因为必须提供额外的真实深度测量。

## 输入如何严格隔离

- TUM Freiburg1 XYZ 官方真实 RGB-D 压缩包重新下载：448,204,271 bytes，SHA256 `a0236d97b8c30cd93b653656d2b6c293ff7c982a4130ef2a1a8beecdb124ef98`，来源 `https://webshare.cvg.cit.tum.de/g/rgbd/dataset/freiburg1/rgbd_dataset_freiburg1_xyz.tgz`。
- 从实拍 RGB 每8张取一张，共90张；FFmpeg 打包成 **4fps 测试 MP4**，不是原生手机 MP4。COLMAP 使用 RGB 和对应的已知内参，真实求得 **90/90** 帧相机轨迹、**9,139** 个稀疏三维点。此阶段完全没有读 TUM 深度/GT 的测量内容。
- **尺度标定才开始使用实测深度**，预先固定索引 **15、45、75**；按RGB原始时间选最接近的传感器深度帧，最大RGB/深度时间偏差 `0.01686` 秒。
- 每帧使用 COLMAP 中实际观测的稀疏匹配点，比较深度传感器测得的相机 Z 与 SfM 相机 Z，比例 `scale = median(depth_m / depth_sfm)`；每帧先取中位数，再取三帧中位数。
- 索引 **5、10、25、35、55、65、85** 的深度帧绝不用于估算尺度，只用来验证得到的米制尺度。
- 直到 `metric-trajectory-from-sensor.json` 写出并锁定，才读取 TUM 真实相机位姿。GT 只用第15帧设置世界原点和朝向，**不调整比例**；其余88帧用于评估相对位置误差。

## 实际测量结果

| 数量/检验 | 实测结果 |
|---|---:|
| RGB 自动 SfM 注册 | 90 / 90 帧 |
| 自动三维稀疏点 | 9,139 |
| 锚点15：有效点数 / 单帧比例 | 1,143 / `0.0522069071` m/SfM 单位 |
| 锚点45：有效点数 / 单帧比例 | 923 / `0.0509981667` |
| 锚点75：有效点数 / 单帧比例 | 866 / `0.0507708730` |
| **仅用3张真实测深计算的比例** | **`0.050998166720` 米 / SfM 单位** |
| 7张未校准深度：可比较稀疏点 | **5,470** |
| 7张未校准深度：按特征点数加权 MAE | **3.907 cm** |
| 7张未校准深度：按特征点数加权 RMSE | **11.459 cm** |
| 仅用第15帧GT姿态固定世界坐标，另外88帧位置RMSE | **1.540 cm** |
| 88帧相机朝向误差中位数 | **0.761°** |
| 事后用所有GT做Sim3得到的**仅供对照**比例 | `0.052329588687` |
| 传感器比例 vs 事后GT最优比例 | `-2.544%` |
| 实验总用时 | 178.765 秒 |

**不要选最好看的数字：** 7张未参与校准的实测深度仍存在较大的误差长尾。例如帧55，稀疏特征深度RMSE为 **30.01 cm**，需要后续检查遮挡、传感器同步、相机误差等可能原因；目前不能直接归因。

## 机器证据文件（Git版本保留，不依赖Actions附件期限）

- `report.json`：真实下载链接/SHA、完整COLMAP命令/错误尾段、测距来源、每锚点点数及分布、七个留出深度验证、后验不缩放GT评估、所有时间/条件。**机器生成，未人工改造。**
- `trajectory-scale-unknown.json`：真实 RGB-only COLMAP 相机位姿；**任意 SfM 尺度**，绝不能冒充米。
- `measured-depth-evidence.json`：三个锚点和七个留出帧与实际深度PNG对应的路径、时间差、传感器类型。源图像未复制进Git仓库；需要重新下载官方数据以复算。
- `metric-trajectory-from-sensor.json`：按传感器尺度换算后的90帧位置、每个观测排除统计、测量哈希；依然不是稠密深度图、TSDF Mesh。

**限制**：只在单一TUM场景、已知相机内参、RGB-D近似同步条件下验证。SFm本身有随机初始化波动；TUM姿态仅在标定之后用于评价世界坐标。即使轨迹有米制平移，这并不说明纯RGB视频能够得出物体的真实尺寸，更不意味着场景几何已经有厘米级精度。下一步是不同视频/传感器交叉验证、独立密集深度恢复与TSDF验证。
