# TUM 真实留出深度：为什么 RMSE 明显大于中位数？

**真实数据实验已完成 · 第一次运行 2026-10-25 · 这是分布分析，不是错误因果证明或独立激光扫描几何精度认证。**

研究档案：[Issue #9](https://github.com/REDrighthand05/echo4d/issues/9)；留出测试基线：[Issue #3](https://github.com/REDrighthand05/echo4d/issues/3)；代码：[Draft PR #10](https://github.com/REDrighthand05/echo4d/pull/10)。

## 输入条件与证据

- 官方 TUM `freiburg1_xyz` RGB-D 原始包，实际下载 448,204,271 字节，已固定 SHA-256 `a0236d97b8c30cd93b653656d2b6c293ff7c982a4130ef2a1a8beecdb124ef98`。
- 用官方提供的相机位姿，使用 48 帧融合为 Mesh，另 12 帧真实深度完全不用于融合；沿用原实验参数，不改体素、不改变评估阈值。
- 第一次实际运行：[Actions #40192049030](https://github.com/REDrighthand05/echo4d/actions/runs/40192049030)，成功。源提交 `df9c91871364369bb14a5d71bfb3d4c7612fd557`。
- 原始留出报告的覆盖率 95.876270914%、MAE 3.1813785cm、RMSE 11.3314712cm、P95 8.107574cm 与新报告**逐数一致**，检测程序拒绝结果不一致。
- 纯分析模块具有 10 个通过的单位测试，包括“一个像素的严重错误主导 RMSE”的故意反例。

## 发现一：非常少的异常像素可以主导整体 RMSE

| 重叠区域中的严重偏差 | 像素数 | 占全部 167,097 个可比像素 | 对所有平方误差的贡献 |
|---|---:|---:|---:|
| >10cm | 5,880 | 3.519% | **95.118%** |
| >30cm | 2,706 | 1.619% | **91.453%** |
| >50cm | 1,999 | 1.196% | **86.083%** |
| >100cm | 678 | 0.406% | **54.954%** |

这是平方误差统计（RMSE 里的平方项）。不能据此宣称 98.8% 像素几何精度达到标准，也不能从原始分数中删除这些错误后宣布性能提高。

## 发现二：误差与测深边缘位置高度相关，但还不能推出真正原因

在**未参与融合的真实传感器深度**上，仅为研究做后验互斥分区：3×3 深度差超过 10cm 为“深度跳变”，扩张到 2 像素；其余分别划入测深缺失边缘、图像 2 像素边框、普通内部。

| 位置类别 | 可比像素占比 | 区域自身 MAE | 对整体平方误差贡献 |
|---|---:|---:|---:|
| 深度跳变邻近 | 18.294% | 9.54cm | **74.093%** |
| 缺失深度邻近 | 10.477% | 4.07cm | **16.697%** |
| 图像边框 | 1.625% | 1.78cm | 0.964% |
| 其他内部 | 69.604% | 1.41cm | 8.246% |

靠近跳变和缺失深度的 28.77% 重叠像素，合计贡献 **90.79%** 的平方误差。但这**不等于已经证明是遮挡引起**：动态物体、像素配准、投影锯齿、深度测量噪声、估计表面与相机轨迹误差，都可能参与其中。

## 下一步不是“删掉边缘”，而是做有对照的原因调查

1. 在同一份保留测试中，独立比较深度边缘两侧预测的正负残差、超大误差分布与真实 RGB/深度不连续线；不将保留帧信息传回建模。
2. 固定模型与参数，做相机位姿扰动/不同投影处理的**诊断对照**，检查是否可预测地改善或恶化残差，避免只做新的截图。
3. 使用不同时间段的连续留出、不同真实序列以及具有激光扫描基准的 ETH3D 进行独立评估。部分跨场景无法比较的区域应明确“未知”，不制造观测。
