# ECHO 历史传感流与时空回访：记录端最小闭环

本文件记录用户的直接产品目标，不是当前硬件已实现声明。ECHO 首先是**持续保存真实生活信息、沿时间轴回访过去**的个人历史系统。三维重建是历史回访的第二种观看方式，而不是录制工作的前置门槛。

## 两种互补的历史观看方式

1. **真实第一人称**：眼镜光轴附近的前向摄像头按时间连续记录视频；回访时按原始时间轴播放**真实拍下来的画面和音频**。不需要 Mesh，不用 AI 重绘原有正前方像素；未拍到的时段保持缺失，不能编造成连续录像。
2. **自由第三人称**：在同一个时刻，融合相机、惯性、实测距离、可用先验网格、跨时刻真实资料，恢复有依据的动态三维空间。使用类似《Detroit: Become Human》调查重建时的可观察线框/网格表达；它是交互风格比喻，不是已具备的技术。未观测区域保留未知；可选预测与高模完善层不覆盖原始重建层。

时间轴上的状态与跨年份知识不同：今天确定了桌子背面形状，可以给历史场景增加有来源的几何知识，但不能因此擅自认定每个年份桌子的具体位置、状态和人物动作都相同。不同年代的物体状态需要各自证据。

## 采集流各自解决的问题

| 来源 | 可直接保存什么 | 对历史重建有什么用 | 目前状态 |
| --- | --- | --- | --- |
| 前向图像/视频流 | 原始清晰视频、采样时间、帧信息与音频（按授权） | 第一人称真实回放；可供后期视觉重建 | 浏览器本地短时录制与回放原型 dist/history.html，非眼镜驱动 |
| IMU 惯性流 | 加速度、角速度和采样时间 | 相机姿态/运动的额外约束，视觉惯性融合可减少漂移 | 原型可选记录浏览器实际报告的设备运动样本；未实现 VIO 位置解算 |
| 标定深度/光学扫描 | 传感器真正测得的可见表面距离 | 高信息场景融合与几何基线 | 已有离线 RGB-D TSDF；可穿戴流式驱动未实现 |
| 其他非电离空间探测 | 具体设备实测的反射、距离或其他原始信号 | 探索遮挡、物体背后或近距离内部结构的**有限**信息补充 | 仅研究候选；没有实现穿墙扫描或可信三维反演 |
| 已有 Mesh/物体数据库 | 有出处、时间和适用条件的旧几何信息 | 恢复未从当时拍摄视角看到的形状 | 现有路线目录含旧Mesh复用，但完整历史配准仍待开发 |

“地质探测”在这里指局部环境结构感知，**不是宣称眼镜要进行传统地质勘测**。某些非电离手段在特定材料及实验条件下可探测部分障碍后的反射，但穿透、分辨率和设备尺寸有显著限制，尤其不能将“收到反射”直接当成已知背面的真实精细 Mesh。主动传感器仅在具备合适设备、合规条件和明确授权后研究；不开辟无依据的生物识别或隐蔽感知功能。

这些流的时间必须分别保留：设备时间、单调采样时间、与统一历史时间轴的校准偏移与误差。未校准的 IMU 不能冒充已知相机世界坐标轨迹。视频压缩后保留实际录制内容，不把为重建降采样的预览代替原始历史记录。

## 本轮真实落地的最小功能

- dist/history.html：在 localhost 浏览器中，由用户主动授权摄像头（请求环境朝向但**不保证**眼镜视线一致），可选授权麦克风、浏览器运动事件。
- 用 MediaRecorder 分批接收视频数据；停止录制后，在浏览器内播放真实录制内容，沿时间轴定位，并查看相邻时间戳的运动传感器读数（如有）。
- 用户分别下载录制的视频文件和 echo-history-stream-0.1 JSON 清单；可重新选择文件在本地导入回放。清单保留运动样本、时间信息，缺传感器信息时仍可以播放视频。
- **实际限制**：浏览器当前先将短时片段放内存（上限180秒），尚无断电可恢复的长期流式落盘、稳定硬件同步、眼镜 IMU 标定、实时 VIO、空间雷达设备、动态人物恢复或时间演化 Mesh。原型录制视频不是精确已知“眼镜正方向位姿”。下载媒体和清单要由用户主动完成。

本地使用：在仓库根目录运行命令 python -m http.server 8080 --bind 127.0.0.1 --directory dist 。

打开 http://127.0.0.1:8080/history.html ，显式开启摄像头，录制几秒，停止，验证回放和拖动时间轴，再分别下载并重新导入视频与清单。不需要深度传感器，不联网传送私人视频。

## 后续研发，不设单视频作为先决条件

优先把真正前向画面流、独立 IMU 流与可靠时间同步长期保存，支持持久写入与断点恢复；保留完整分辨率的原始记录。之后接入已有可运行的高信息场景融合（已知位姿＋实测深度＋其他已有几何），形成时变场景，再按需尝试减少传感器信息。可见范围之外的探测只经合法设备实测与独立几何校准后成为新的“有来源观测”，不能由假设自动成为真实 Mesh。

首个直接有用的里程碑：**打开五分钟的真实记录，沿时间轴随时播放实际前方画面；对该时刻能关联已知移动与几何则展示，未知则明确留空。** 它不依赖最难的单视频三维还原先成功。
