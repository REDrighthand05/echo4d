## 新增验收

1. 唯一 import-colmap CLI 实际导入已知相机中心；位置按比例换算，米制深度不二次缩放。
2. A/B 两组12张检查的名字、顺序、原始深度文件名/SHA、RGB 时间/测深间隔、每帧有效像素数及汇总均一致后，才可写 same-input=true。两组预测覆盖可以不同。
3. 对来源错配、缺帧、像素计数错配、伪造尺度/单位和非有限误差提供失败检查。
4. A/B 机器报告区分 tested_checkout_sha、pr_head_sha、base_sha；git_sha 指向实际测试 checkout。既有历史报告原样保留。
