# Redwood real bedroom: measured RGB-D reconstruction

These five views and colored GLB are generated by stock Open3D
ScalableTSDFVolume from 360 original-resolution RGB-D observations
and the corresponding recorded camera poses.

Photo-vs-mesh images: left = original photo, right = newly fused Mesh.
Free-view images: Mesh only, novel camera viewpoints.

No existing prior reconstruction was fused into this Mesh.
The supplied prior is separate in the full run artifact.
Human recognizability and accuracy are NOT yet accepted.

Source: https://redwood-data.org/indoor_lidar_rgbd/
Engine: https://github.com/isl-org/Open3D
