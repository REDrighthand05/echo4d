# 运行与生产接入

这是离线批处理内核，没有网络后端服务。浏览器导入文件在当前页面处理；内置实拍样例仅通过静态下载载入。源码没有遥测、账户或云模型调用。

成功时最后一行 stdout 为 JSON，进度和错误写 stderr。输入错误返回 2，正常取消返回 130。完成整批输出后才将临时目录重命名为结果目录；失败清理临时输出并拒绝已有目标目录。强制终止/断电仍会留下临时目录，确认进程停止后可手动清理。任务应使用不可变输入和独占输出目录。

报告不哈希自身；耗时会变化。同一锁定环境、输入和参数下 PLY 重复性已测试。每体素数组 32 字节；默认 400 万体素约 128 MB，仅为数组预算，不是峰值内存。网格提取与临时数组增加峰值。32M 体素硬上限不保证机器可承载。

体素中心从最小边界 + 半体素开始，各轴数量向上取整；最后中心最多超出给定最大边界半体素。观测计数是最近体素的输入帧支持数，不是三角形共享证据交集或置信概率；首末时间也不代表期间连续观测。

TSDF 用 measured_depth - voxel_camera_z，截断并等权累积；颜色仅在近表面带累积。Marching Cubes 后只保留所在单元八个角全部满足最小观测数的面，避免未知边界假表面。

当前使用最近像素投影、稠密有界体积，无深度方差模型、畸变校正、动态分割、空间哈希、GPU 加速、回环或地图重优化。反光、透明、薄物体、遮挡边缘和定位错误会影响结果。网格不保证无自交或可打印；报告仅统计零面积面、边界边和非流形边。

Canvas 兼容模式使用面深度排序，骨架是诊断叠加；精确遮挡应使用 WebGL 或外部网格工具。浏览器基线可能存在跨帧重复面，与原生 TSDF 分别标记。

部署验收仍需：目标设备的尺度/畸变/时间/坐标校验；独立扫描参考与预先确定的精度覆盖门槛；长序列、峰值内存、磁盘耗尽、进程强杀与并发测试；人体坐标和动态掩码验证。若包装为上传服务，还需认证、授权、进程隔离、配额、排队和取消。输入校验不等于操作系统沙箱。

Dockerfile 已提供但交付环境未构建容器。CI 配置和本地测试与远端 CI 结果应分别核实。
