# ECHO 总体设想

_这页说要去哪、为什么。和《现状总账》配对：那页记现在在哪、已经发生了什么；这页是瞄准用的图，先锋往哪打看这页。_

---

## 本体

**ECHO 不是"视频变 3D"的工具，是把生活存成可以重进的现场的系统。**

记录是底片，软件是显影液：同一份记录能显出多少东西，看两件事——存的时候存得多全，以后的理解力涨多快。能用久的资产是记录本身，重建的方法随时可以换、可以升级。所以次序永远是：**先把记录存全、存对，显影的事慢慢长。**

一份记录会被显影成四层，由低到高。下面每层都写清四件事：是什么、为什么值钱、现在站在哪、缺的输入是什么。

---

## 四层显影

### 第一层 · 空间层（哪里是哪里）

| | |
|---|---|
| 是什么 | 一个地方的形状、真实尺寸、和走过它的路线 |
| 为什么值钱 | 这是地基。上面三层全站在它的坐标上：没有真实尺寸，量距离是假数、两次记录拼不到一起、重活时身临其境的尺度感也是假的 |
| 现在站在哪 | 单次这一程基本走完：一个视频自动建成完整场景，形状对、自动摆正、边缘清理过；真尺度已经试验证明能从片子里的标准物算出来（开关面板当锚，估计误差 ±10%），正在做进软件；走过的路线能在成品场景里重走一遍 |
| 缺的输入 | 还差"多次记录合成一个"：试验证明成品对成品事后硬拼是死路，活路是降一层——算位置时就把第二次的照片注册进第一次的重建，外加一条拍摄规矩，每次拍摄走回起点闭环。路线已定，未做进软件 |

### 第二层 · 物体层（什么是什么）

| | |
|---|---|
| 是什么 | 认出场景里每件东西的身份、真实尺寸、位置和朝向 |
| 为什么值钱 | 房间从"一堆点"变成"一张有名字的物品清单"：能按东西找记录，能单独把一件东西拎出来看，重活时每件东西都有名有姓。驱动这一层的引擎是**强发现**——主动扫遍画面，把所有尺寸可知的东西都挖出来，不等谁指定 |
| 现在站在哪 | 强发现的第一个用途已经证了：找标准物当锚、给整个场景定真尺度（86 型面板就是这样找到的）。整屋物品清单还没试过 |
| 缺的输入 | 不缺硬件，缺的是把发现的范围从"找锚"扩到"认全屋"：先认尺寸写在标准里的物件，再扩到型号可查的日常物；多个发现互相咬合才算数，咬不上就明说没认出来 |
| 长期位置 | 眼镜时代也**保留**，不退休：传感器给的尺度要有人校验，从画面里独立认物定尺就是那道校验——这是优质冗余，传感器越强它越值钱 |

### 第三层 · 事件层（发生了什么）

| | |
|---|---|
| 是什么 | 谁，在什么时候，做了什么 |
| 为什么值钱 | 空间和物体只是现场的壳，事件才是生活本身。这一层显出来，记录才从"一个地方"变成"一段日子" |
| 现在站在哪 | **只守不攻。** 现在能做的只有一件事，而且必须做好：记录的存法要把将来显影要用的信息全留住——原始画面不丢、各路信息同步、时间戳对齐、原件就是原件 |
| 缺的输入 | 这一层的解锁不在软件，在输入：一双眼镜在拍摄那一刻同时收下画面、声音、位置和朝向，事件才有据可查。眼镜没到之前，谁声称能从一段手机视频里显出事件层，谁就是在编 |

### 第四层 · 重活层（再过一遍）

| | |
|---|---|
| 是什么 | 把前三层重新放给人经历：看着自己当时的路线走一遍，或者站回当时的位置再看一遍 |
| 为什么值钱 | 这是整个系统的出口。前面三层存得再厚，最终都要在这一层变成"又回去了一次"的感受 |
| 现在站在哪 | 第三人称路线回放已经有了：小人沿你当时的路线在成品场景里走。重建过程的实时预览，原型已证跟得上（渲染永远不是瓶颈） |
| 缺的输入 | 第一人称"回到那一刻"未动。它不缺单项技术，缺的是下面两层的厚度——空间层要真、物体层要有名字，它站上去才不空 |

## 先锋怎么瞄

先锋不按功能派，按层派。每一波、每一层只问一句话：

> **这一层的信息，现在的记录榨得出来吗？**

规矩四条：

1. **判据事先定死**——出发前就写明什么算成、什么算不成，不到了现场再改口。
2. **成了就合并**——试出来的活路进软件、进账本，不留在试验田里。
3. **不成就记账**——明确记下缺的是什么输入（多半是眼镜的传感器），然后停手，不硬攻。
4. **不空谈顺序**——顺序由试验结论长出来，不靠开会排。账本只有一本：《现状总账》。

## 眼镜的位置

眼镜是这套系统的终局输入设备，不是另一个产品。

它到的那天，变的只有输入：尺度、位置、深度在拍摄那一刻就直接有了，空间层的硬骨头大半消失，事件层随之解锁。但软件这四层显影能力原样复用，一层都不浪费——这正是现在值得一层层往上建的原因：**今天在手机视频上练出来的每一层理解力，眼镜时代直接继承；今天存下来的每一份合格记录，眼镜时代还能重新显影。**

反过来也成立：在眼镜到来之前，所有"从一段普通视频里猜出本不存在的信息"的做法都要标清是估计，猜不出的就明说缺输入。这是这个系统和"演示玩具"的分界线。
