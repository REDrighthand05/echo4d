# ECHO 开源/可编程雷达摸底（2026-11-01）

问题只有一个：**哪种雷达能把最底层数据交到我们自己手里**（逐方向测距 / 点云 / 原始 I/Q·ADC），而不是像 LD2450 那样只递一张厂家算好的结论单。
约束：电脑算力、不焊接、模块级拼装、雷达部分预算理想 <¥600。价格为 2026-11-01 检索的公开渠道价（官方价/分销价/平台价折算，汇率约 ¥7.2/$），淘宝实际价以店铺为准。

## 一、逐项摸底

### 1. Acconeer A121 / XM125（60GHz 脉冲相干雷达，瑞典）
- **数据层级：准原始 I/Q。** 官方 SDK 的 Sparse IQ 服务直接输出**每个距离格（distance bin）的复数 I/Q（幅值＋相位）**——相位能做到亚毫米级位移感知（呼吸检测论文就用它）。这不是 ADC 原始采样，但它是雷达信号处理链里公认的"自己可算"层：距离谱、速度、微动全由我们自己的程序从 I/Q 算，厂家只给测量不给结论。另有 Envelope 服务和开源的参考检测器（存在/距离检测器源码在 SDK 里）。
- **致命短板：单发单收，没有角度。** 它只是一条射线上的距离剖面，"哪个方向"它不知道。要逐方向扫描，必须把它装上转台旋转，或摆多个——这是用它建图要自己补的一课。
- **开放程度：** Exploration Tool（Python 上位机）在 GitHub 开源；SDK（RSS）免费下载、**专有许可**（可商用开发、非 OSI 开源）；GitHub 上第三方库和论文代码很多，生态健康。
- **价格：** A121 芯片约 ¥90–100（Mouser 单颗）；XM125 模块约 ¥225（Alibaba $31）；SparkFun 转接板（带 USB、Qwiic 免焊）约 ¥360（$50）；官方评估套件 XE125 约 ¥850–880（$117–121）。国内有 Acconeer 中国站和代理，淘宝多为 SparkFun 板和模块，约 ¥230–450。
- **契合度：** USB-C/UART 直连电脑、零焊接；模块价在预算内。**雷达里唯一在 ¥600 内能摸到 I/Q 的。**

### 2. TI mmWave IWR6843 / IWR1843（60/77GHz FMCW，3发4收）
- **数据层级：两档。** ①开箱固件经 UART/USB 输出**点云**（每点 x/y/z/速度/信噪比）——点是真测量、归我们，但 FFT＋CFAR 检测是 TI 片上 DSP 算的，算不算"结论"介于中间：SDK 源码开放，可改链路、可输出距离剖面等中间量，比 LD2450 深得多。②**原始 ADC** 必须加 DCA1000EVM 采集卡（LVDS 转千兆以太网），配 mmWave Studio 录 .bin，之后 FFT 链全归我们——这是消费级能摸到的最底层。
- **价格（全套算账）：** 评估板官方 $172–202 ≈ **¥1,240–1,460**（AliExpress 溢价 $260–330）；DCA1000 官方标价已涨到 $691.8、深圳渠道约 $547–562 ≈ **¥3,950–4,950**；ISK 类板接采集卡常还要 MMWAVEICBOOST 载板 $287.6 ≈ ¥2,070。**点云路线总价 ≈¥1,300–2,400；原始 ADC 路线总价 ≈¥5,500–8,500。** 雷达预算 ¥600 连评估板都买不齐。
- **开放程度：** mmWave SDK 与示例源码可得（TI 许可，非 OSI）；GitHub 上解析器/ROS 驱动生态庞大（多为第三方）。
- **契合度：** 免焊、USB 直连没问题，卡在钱。学术界标准件，数据主权真，但不是这一波的价位。

### 3. Infineon BGT60TR13C（60GHz FMCW，1发3收，天线封装）
- **数据层级：真原始 ADC。** 芯片经 SPI 把 ADC 采样原样吐给主控，芯片内**不做任何信号处理**，FFT/检测/跟踪全在电脑端——数据主权是这几家里最干净的。官方 Radar Development Kit（RDK）给原始数据接口＋Python/C 例程，Radar Fusion GUI 可看原始信号。
- **代价：** DEMO 套件 Mouser $224.65 ≈ ¥1,620、Farnell €126.6 ≈ ¥980，**且多家分销商交期标 52 周/缺货**——有钱也未必近期买得到；3 个接收通道只能算粗方位角；RDK 需在 Infineon 开发者中心注册下载、专有许可。
- **契合度：** 数据层满分，价格超预算 2 倍＋供货风险。观察名单，不是现在的先锋。

### 4. 真·DIY 开源相控阵 / 自制 FMCW 雷达（GitHub 众项目）
- ADI Phaser（CN0566，ADAR1000＋PlutoSDR）官方套件 $2,875–3,162 ≈ **¥20,700–22,800**，且是 10GHz 波束赋形**教学平台**，不是开箱建图雷达，还要自己做校准和测距链。
- GitHub 上的开源 FMCW 项目（自研 FPGA＋射频板、开源 24GHz 收发芯片设计等）全是**专家级射频 PCB 工程**：多层阻抗控制板、贴片回流焊、矢量网络分析仪校准，工期以月计。
- **直说物理账：** 24GHz 波长 12.5mm、60GHz 波长 5mm——杜邦线和面包板孔距在这个频段本身就是天线和反射体，射频部分**物理上无法面包板化**。能免焊碰的只有成品模块的数字接口。"自己搓相控阵"在本项目约束下是幻想，不是难度问题，是物理问题。

### 5. 对照组：逐方向测距的现任便宜货（非雷达，但数据最干净）
- **LDROBOT LD06 / LD19（360° 2D 激光雷达）：** 串口直出**每个点的角度＋距离＋强度**，4500–5000 点/秒、12m、360°——扫描即原始测量，中间没有厂家结论层；协议公开、LDROBOT 官方 ROS 驱动开源。海外批发价 $40–105，国内零售约 **LD06 ¥199–299 / LD19·D500 套件 ¥299–499**。短板：只有一个水平面、光学怕玻璃和烟尘、有转动电机、没有速度、穿不了遮挡——它不是雷达，是"逐方向测距"这件事目前的性价比基准线。
- **VL53L5CX 8×8 ToF（¥70–95，本波已定）：** 64 格直读距离，同样是原始测距无壳，只是格子粗、量程约 4m。
- **旋转单点 ToF（VL53L1X ¥15＋舵机 ¥10）：** 最廉价的逐方向扫描实验法，一圈数秒，适合验证"扫描→建图"链路，不适合当产品件。

## 三、结论（先锋指向）

**值得上手实测的两个：**
1. **Acconeer XM125（先锋 R1）**——¥600 内唯一的"雷达＋I/Q 数据主权"。先锋问题：把模块架上慢速转台，Sparse IQ 流能否落进我们的记录格式、逐格 I/Q 在电脑端算出的距离剖面够不够拼出一张极坐标扫描图。成，它就是雷达线的原始层入口；败，败得便宜（¥225 起）。
2. **LD06（先锋 R2，对照基准）**——不是雷达，但它是逐方向原始测距的现任标杆：先用它把"扫描→记录→建图"的链路和真值立起来，以后任何雷达（XM125 旋转扫描、TI 点云）都拿它当对照判分。¥200 买一条基准线，不亏。

**是幻想的：** 自己搓相控阵（物理排除）、TI 原始 ADC 全家桶（预算近 10 倍）、指望破解 LD2450 拿原始数据（硬件上无此通路，已定论）。
**观察名单：** TI IWR6843 点云路线（预算松动到 ¥1,500 时它是雷达建图的正解）、Infineon BGT60TR13C（数据层最干净，等供货和价格正常化）。
