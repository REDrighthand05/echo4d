# ECHO 采集头 · 接线与总线预案（到货日用，2026-11-01 晚备）

前提：免焊，面包板+杜邦；主控 ESP32-CAM 套装；算力与存储在电脑端。

## 总线规划（一根 I2C 养五件）
五件 I2C 器件地址互不冲突，共挂一根总线（SDA/SCL 两线并联即可）：
| 器件 | I2C 地址(7bit) | 流入记录 |
|---|---|---|
| VL53L5CX 8×8 ToF | 0x29 | tof.csv（格式原生支持，64 区 mm） |
| MPU-6050 (GY-521) | 0x68 | imu.csv（格式原生支持；自带温度读数→声速补偿备用） |
| BME680 | 0x76/0x77 | env.csv（新增流：温/湿/气压/气质） |
| QMC5883L 磁力计 | 0x0D | mag.csv（新增流：三轴磁场→航向） |
| AS7341 光谱 | 0x39 | spec.csv（新增流：11 通道光谱） |
新增流均为向后兼容的新文件，记录格式骨架（单调时钟+meta.json）不动，reader 需同步放行新文件名——到货前由 Muse 备好。

## 引脚预算（ESP32-CAM 的紧处，先知道）
- 摄像头占去大部分引脚；TF 卡**不插**（插了再占 2 脚）。
- I2C 总线取 GPIO14=SDA / GPIO15=SCL 一组（待到货后按套装实际引出复核）。
- INMP441 麦克风走 I2S 需 3 线，是全场最紧的一处：预案 A 用 GPIO12/13/2 挤出；预案 B 麦克风第二步再上（先跑通五件 I2C + 相机）。到货日按实物定，不硬套。
- LD2450 已出局，不占串口——串口留给调试/回传。

## 到货日顺序（不变）
1. 只插主控+相机，通电连电脑，确认图能回传；
2. I2C 五件逐件挂上逐件验地址（一次一件，地址对上再下一件）；
3. 全件同挂，走一圈闭环，第一份多流记录落盘；
4. 验三件事：时间戳对齐 / 数据像房间 / 记录能回放。
