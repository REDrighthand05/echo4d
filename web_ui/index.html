毛玻璃

          

            
            
主界面模糊度
主界面那张毛玻璃糊多少

            
            
          

          

            
            
主界面乳白深度
玻璃上乳白罩的浓淡

            
            
          

          

            
            
主界面鲜明度
透过玻璃的背景颜色鲜明程度

            
            
          

          

            
            
运行态雾度
任务运行时的玻璃：0 是几乎全透（现在这样），往右拉雾变重；下次运行生效

            
            
          

        

        

          
毛玻璃 · 设置页

          

            
            
设置页模糊度
这一页的罩糊多少，拖动当场就变

            
            
          

          

            
            
设置页背景深度
这一页罩的颜色深浅

            
            
          

          

            
            
设置页鲜明度
透过这一页的涂鸦颜色鲜明程度

            
            
          

        

        

          
背景涂鸦

          

            
            
涂鸦笔数
每手涂鸦几笔；「随机」是每次打开不一样（松手换一手生效）

            
            
          

          

            
            
笔触粗细
巨笔的粗细倍率（松手换一手生效）

            
            
          

          

            
            
涂鸦浓度
整面涂鸦墙的浓淡

            
            
          

          

            
            
涂鸦鲜明度
涂鸦颜色的鲜明程度

            
            
          

          

            
            
换一手涂鸦
立刻重新随机一手，跟每次打开软件换的那种一样

            
          

        

        

          
雾点

          

            
            
雾点密度
组成涂鸦的小点多少；拉到 0 墙就空了（松手生效）

            
            
          

          

            
            
雾点大小
每个小点的大小倍率

            
            
          

        

        

          
常态动效

          

            
            
动效开关
关掉后涂鸦和雾点都静下来

            
          

          

            
            
动效速度
涂鸦呼吸、游走和光泽扫过的快慢

            
            
          

          

            
            
动效幅度
涂鸦游走和呼吸的劲儿大小

            
            
          

          

            
            
光泽扫过
每隔一阵，一道淡光斜扫过整张玻璃
